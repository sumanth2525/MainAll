## Run this directory locally

Serve the repository with any static HTTP server, for example:

```bash
git clone https://github.com/sumanth2525/MainAll.git
cd MainAll
python -m http.server 8000
```

Open http://localhost:8000. The page loads external Google Fonts and Firebase SDKs. Its live presence counter depends on Firebase connectivity and database rules.
